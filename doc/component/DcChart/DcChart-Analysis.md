# DcChart.vue アーキテクチャ分析

## 概要

DcChart.vueは9,978行の巨大な単一Vueコンポーネントで、元々jQueryベースのコードベースをVue 3 Composition APIに移植したものです。現在の実装はモノリシックで、複数の関心事が一つのコンポーネントに混在しています。

## 現状のアーキテクチャ

### mm オブジェクトの構造分析

すべての機能が`const mm`オブジェクトに集約されています：

#### 1. 設定関連 (`mm.config.*`)
- **責務**: アプリケーション全体の設定値管理
- **内容**:
  - パネルのドラッグ・リサイズ設定
  - チャートのデフォルトマージン
  - 各チャートタイプの設定（幅、高さ、色など）
  - マウス操作設定

#### 2. オプション管理 (`mm.opt.*`)
- **責務**: 動的なチャートオプション管理
- **内容**:
  - 各チャートの表示オプション
  - スケール設定
  - 凡例表示設定
  - エラスティック設定

#### 3. チャートインスタンス (`mm.chart*`)
- **責務**: DC.jsチャートオブジェクトの管理
- **内容**:
  - `mm.chartDate`, `mm.chartAge`, `mm.chartSex`等
  - `mm.chartEx[]` - 拡張チャートの配列
  - `mm.composite` - 複合チャート

#### 4. ユーティリティ (`mm.util.*`)
- **責務**: 共通的なヘルパー関数
- **内容**:
  - データフォーマット関数
  - スケール計算
  - 文字列処理
  - 数値計算

#### 5. チャート操作メソッド (`mm.chart.*`, `mm.render*`, `mm.filter*`)
- **責務**: チャートの描画・更新・フィルタリング
- **内容**:
  - チャート描画処理
  - フィルター操作
  - イベントハンドリング

#### 6. データ管理
- **責務**: Crossfilterとデータグループの管理
- **内容**:
  - `mm.ndx` - Crossfilterインスタンス
  - `mm.gp*` - データグループ
  - `mm.dim*` - ディメンション

#### 7. URL管理
- **責務**: URLパラメータとの同期
- **内容**:
  - `mm.onChangeURL()` - URL更新処理
  - パラメータの読み込み・保存

## 主要な課題点

### 1. 単一責任原則の違反
- 一つのオブジェクトが多すぎる責務を持っている
- 設定、状態、ロジック、表示が混在

### 2. 再利用性の欠如
- コンポーネントが分割されていない
- 共通処理が抽出されていない

### 3. テスタビリティの低さ
- 密結合で単体テストが困難
- 副作用が多い

### 4. 保守性の問題
- コードの可読性が低い
- 変更影響範囲が予測困難

## チャートタイプ分析

現在サポートされているチャートタイプ：

1. **時系列チャート** (`chartDate`, `chartDate2`)
2. **年別チャート** (`chartYear`)
3. **季節チャート** (`chartSeason`)
4. **曜日チャート** (`chartWeek`)
5. **性別チャート** (`chartSex`)
6. **年齢チャート** (`chartAge`)
7. **状態チャート** (`chartCond`)
8. **職業チャート** (`chartJob`)
9. **地域チャート** (`chartName`, `chartCity`)
10. **拡張チャート** (`chartEx[0-15]`)

## テンプレート構造分析

### パネル構成
- **ツールバー**: 検索、フィルタークリア、レイアウト変更
- **メインチャート**: 時系列データ表示
- **サイドパネル**: 各種フィルタリングチャート
- **詳細パネル**: 選択されたデータの詳細表示
- **マップ関連**: GoogleMap、ストリートビュー連携

### UI状態管理
`pnl` reactiveオブジェクトでパネルの表示状態を管理：
- 各パネルの表示/非表示
- スタイル設定
- ドラッグ&ドロップ状態

## 依存関係分析

### 外部ライブラリ
- **DC.js**: データ可視化
- **D3.js**: データ操作・描画
- **Crossfilter**: データフィルタリング
- **Moment.js**: 日付処理
- **Lodash**: ユーティリティ
- **jQuery**: DOM操作（レガシー）

### 内部依存
- コンポーネント間の依存が複雑
- グローバル状態への依存が強い
- イベントハンドリングが分散
