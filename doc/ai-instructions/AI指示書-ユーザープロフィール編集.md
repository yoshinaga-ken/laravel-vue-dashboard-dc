# AI作業指示書: ユーザープロフィール編集

## 使用方法

この指示書を使用するには、AIエージェントに以下の1文を指示してください：

```
@AI指示書-ユーザープロフィール編集.md 
の内容を確認して作業を進めて下さい。
```

## 実装対象機能

**機能名**: ユーザープロフィール編集

**実装状況**: 20%

**機能要件ファイル**: `.kiro-x/spec/2-user-profile-ユーザープロフィール画面の新規作成.md`

**機能仕様書**: `.kiro-x/design/2-user-profile-ユーザープロフィール画面の新規作成-design.md`

**システム仕様書**: `doc/system/user-profile.md`

**想定URL**: `http://127.0.0.1:8000/users/{userId}/edit`

## 概要

任意のユーザーのプロフィール情報を編集する画面です。現在はGraphQLでユーザー情報を取得してJSONでPrintしているだけで、UIは未実装です。テスト的に、ユーザーの記事0番目のタグを編集するUIだけは実装済みです。

## 現在の実装状況

### 実装済み

- GraphQLでUserデータ取得とprint表示
- ユーザーの0番目の記事のタグ編集フォーム（テスト実装）

### 未実装

- プロフィール情報編集UI（名前、メールアドレス、プロフィール写真等）
- フォームバリデーション
- エラーハンドリング
- 保存機能の実装

## 実装手順

以下のステップを順番に実行してください。**人間への確認は不要です。最後まで自動的に進めてください。**

### ステップ1: ブランチ作成と準備

1. **featureブランチの作成**

   ```bash
   git checkout -b feature/user-profile-edit
   ```

2. **関連ドキュメントの確認**
   - `.kiro-x/spec/2-user-profile-ユーザープロフィール画面の新規作成.md` を確認
   - `.kiro-x/design/2-user-profile-ユーザープロフィール画面の新規作成-design.md` を確認
   - `doc/system/user-profile.md` を確認
   - [spec駆動開発手順書](.kiro-x/rule/spec駆動開発手順書.md) を確認
   - 既存の実装コードを確認
     - `resources/js/Pages/Users/Edit.vue`
     - `resources/js/Pages/Profile/Show.vue`（参考）

### ステップ2: 実装タスクの確認と実装

1. **実装タスクの確認**
   - `.kiro-x/tasks/2-user-profile-task-*.md` を確認
   - 依存関係を確認（タスク番号が小さい順に実装）

2. **実装の実行**
   - spec駆動開発手順書に従って実装
   - 依存タスクから順に実装（基本コンポーネント→ページコンポーネント、バックエンドAPI→フロントエンド）
   - GraphQLを使用した通信方式を維持
   - Element Plusコンポーネントを使用

3. **動作確認**
   - 各実装タスク完了後、@Browserで `http://127.0.0.1:8000/users/{userId}/edit` を表示
   - 仕様書通りに機能が正しく動作するか確認
   - 誤りがある場合は修正してからcommit

4. **Commit**
   - 動作確認後にcommit
   - commitメッセージ: `TASK-{タスクナンバー}: {実装内容タイトル}`
   - 誤りがある場合は `git commit --amend` で修正

### ステップ3: プルリクエスト作成

1. **実装完了後の確認**
   - 全ての実装タスクが完了しているか確認
   - @Browserで全機能が正しく動作するか確認

2. **プルリクエスト作成**
   - 実装完了後にプルリクエストを作成
   - 実装内容を説明するPR説明文を作成
