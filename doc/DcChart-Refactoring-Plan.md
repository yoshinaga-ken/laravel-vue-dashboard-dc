# DcChart.vue 段階的リファクタリング計画

## 目標アーキテクチャ

### 新しい構成

```
src/
├── Components/
│   ├── DcChart/                    # メインコンポーネント
│   │   ├── DcChart.vue            # 軽量化されたメインコンポーネント
│   │   ├── DcChartToolbar.vue     # ツールバー
│   │   ├── DcChartLayout.vue      # レイアウト管理
│   │   └── panels/                # パネルコンポーネント群
│   │       ├── DcDatePanel.vue
│   │       ├── DcAgePanel.vue
│   │       ├── DcSexPanel.vue
│   │       └── ...
│   └── Charts/                     # 個別チャートコンポーネント
│       ├── DcTimeSeriesChart.vue
│       ├── DcBarChart.vue
│       ├── DcPieChart.vue
│       └── ...
├── Composables/                    # 再利用可能ロジック
│   ├── useChartConfig.ts           # チャート設定管理
│   ├── useChartData.ts             # データ管理
│   ├── useChartFilter.ts           # フィルタリング
│   ├── useUrlSync.ts               # URL同期
│   └── charts/                     # チャート固有ロジック
│       ├── useDateChart.ts
│       ├── useAgeChart.ts
│       └── ...
├── Services/                       # ビジネスロジック
│   ├── ChartService.ts            # チャート操作
│   ├── DataService.ts             # データ取得・変換
│   └── ConfigService.ts           # 設定管理
└── Types/                         # TypeScript型定義
    ├── chart.types.ts
    ├── data.types.ts
    └── config.types.ts
```
