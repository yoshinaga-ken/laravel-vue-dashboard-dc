# spec駆動開発手順書

- 本ドキュメントは、ある機能要件を実装するにあたり、設計～実装までの作業の流れを示したドキュメントである

## 1. `機能仕様書`の作成

- 本、`spec駆動開発手順書.md`と一緒に渡された機能要件ファイル(`.kiro-x/spec/{要件名}.md`)を確認し、その要件を満たす`機能仕様書`
  を以下に作成してください
  - `.kiro-x/design/{要件名}-design.md`
- 現システムの機能を把握した上で、必要な機能を洗い出し、`機能仕様書`にまとめてください
- 現システムの機能を把握する場合は、必要に応じて以下を参照してください
  - [DeepWiki リファレンス](https://deepwiki.com/yoshinaga-ken/laravel-vue-dashboard-dc)
  - [現システムのシステム仕様書](doc/sysutem/*.md)

## 2. 上記`機能仕様書`のレビュー

- 作成した`機能仕様書`のレビューを人間が行うので、一旦作業はここで止めて、レビュー依頼を出してください
- レビューで修正がある場合は、前のステップに戻って修正してください
- レビュー修正がない場合は、次のステップへ進んでください
