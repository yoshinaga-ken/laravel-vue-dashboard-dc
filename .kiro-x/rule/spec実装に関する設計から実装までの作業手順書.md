# spec実装に関する設計から実装までの作業の流れ

## 1. `機能仕様書`の作成

- この作業手順書と一緒に渡された機能要件のドキュメントを確認し、その`機能仕様書`を以下に作成してください
  - `.kiro-x/design/{要件名}-design.md`

(ここにルールを記述します)

## 2. 上記`機能仕様書`のレビュー

- 作成した`機能仕様書`のレビューを人間が行うので、一旦作業はここで止めて、レビュー依頼を出してください
- レビューで修正がある場合は、前のステップに戻って修正してください
- レビュー修正がない場合は、次のステップへ進んでください

## 3. `実装タスク仕様書`の作成

- `機能仕様書`の内容を実装するにあたって、独立可能な機能実装をタスクとして分割して、タスクごとに以下のファイルにまとめてください
  - `.kiro-x/tasks/{要件名}-task-{タスク番号}-{title}.md`

(ここにルールを記述します)

## 4. 上記`実装タスク仕様書`のレビュー

- 作成した`実装タスク仕様書`のレビューを人間が行うので、一旦作業はここで止めて、レビュー依頼を出してください
- レビューで修正がある場合は、前のステップに戻って修正してください
- レビュー修正がない場合は、次のステップへ進んでください

## 5. `実装タスク仕様書`の実装

- `実装タスク仕様書`内のタスク `.kiro/tasks/{要件名}-task-{タスク番号}-{title}.md` を実装していきます
